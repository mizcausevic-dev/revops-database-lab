# Security Policy

## Supported Scope

This repository is a portfolio artifact and demonstration dataset. It does not ship production credentials, live customer data, or deployment secrets.

## Reporting

If you identify a security issue in the repository structure, sample data, CI setup, or documentation, please open a private security advisory or contact through the public portfolio channels linked in the README.

## Data Handling Notes

- Sample records are fictional
- No production secrets should ever be committed
- `.env.example` is provided for local setup only
